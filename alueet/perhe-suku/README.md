# Perhe / suku

*Päivitetty: 2026-11-08 · Esimerkkidataa: Aino Esimerkki on keksitty henkilö.*

## Tarkoitus
Perhe on arjen perusta: läsnäolo lapsen kanssa ja yhteys vanhempiin.

## Lyhyt aikaväli
- Yhteinen ruokailu arki-iltaisin vähintään 4 kertaa viikossa
- Soitto vanhemmille joka sunnuntai

## Pitkä aikaväli
- Lapsella on turvallinen ja kiireetön lapsuus
- Sukutapaaminen kerran vuodessa

## Linkittyy
- **Parisuhde:** yhteiset perheillat ovat myös parisuhdeaikaa.
- **Henkinen hyvinvointi:** kiireetön ilta palauttaa.

## Nykytila
Arki-illat ovat kiireisiä harrastusten takia; yhteisiä ruokailuja noin 3 viikossa.
