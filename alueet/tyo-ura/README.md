# Työ / ura

*Päivitetty: 2026-11-08 · Esimerkkidataa: Aino Esimerkki on keksitty henkilö.*

## Tarkoitus
Työ, joka tuo energiaa ja jossa pääsee hyödyntämään tekoälyä.

## Lyhyt aikaväli
- Vastuu yhdestä tekoälyä hyödyntävästä palvelumuotoiluhankkeesta
- Kevyempi kuormitus: ei töitä iltaisin

## Pitkä aikaväli
- Tekoälyä hyödyntävän palvelukehityksen asiantuntija- tai johtorooli

## Linkittyy
- **Kehitys:** tekoälyopinnot.
- **Henkinen hyvinvointi:** ilta-töiden karsiminen.
- **Perhe:** vapaat illat.

## Nykytila
Palvelumuotoilun tiiminvetäjä keksityssä Esimerkki Oy:ssä. Ensimmäinen tekoälypilotti käynnistyy joulukuussa.
