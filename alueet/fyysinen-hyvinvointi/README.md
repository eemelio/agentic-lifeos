# Fyysinen hyvinvointi

*Päivitetty: 2026-11-08 · Esimerkkidataa: Aino Esimerkki on keksitty henkilö.*

## Tarkoitus
Liikunta, uni ja ravinto pitävät jaksamisen kunnossa.

## Lyhyt aikaväli
- Uinti kerran viikossa
- Uni vähintään 7 h viitenä yönä viikossa
- Lounas ilman ruutua

## Pitkä aikaväli
- Liikkuu säännöllisesti ilman pakkoa

## Linkittyy
- **Harrastukset:** metsälenkit.
- **Henkinen hyvinvointi:** uni ja liike.

## Nykytila
Uinti toteutuu; uni jää alle 7 h noin kahtena yönä viikossa.
