# Talous

*Päivitetty: 2026-11-08 · Esimerkkidataa: Aino Esimerkki on keksitty henkilö.*

## Tarkoitus
Rauha siitä, että raha riittää ja yllätykset eivät kaada.

## Lyhyt aikaväli
- Puskurirahasto 3 kuukauden menoihin vuoden loppuun mennessä
- Kuukausibudjetin seuranta 15 min / kk

## Pitkä aikaväli
- Asuntolaina puoleen 5 vuodessa

## Linkittyy
- **Perhe:** yhteiset säästötavoitteet.
- **Henkinen hyvinvointi:** taloushuoli vie unet.

## Nykytila
Puskuri noin 60 % tavoitteesta (pyöristetty). Tarkat luvut ovat `private/`-kansiossa.
